Help

1. Hover over Frame Template on the left to open the dropdown. Frame folders become category/subcategory filters automatically; after filtering, hover previews a frame live and click selects it.

2. Set the background matte first. It can stay a classic box, use a background image, or become a Triangle / Circle / Hexagon. Enable the purple overlay to move, rotate, scale, or squish it.

3. Upload an image or paste a direct image URL. Open Position & Resize in this same section for Zoom / Position / Rotation / Fit / Fill.

4. Font and text editing are grouped on the right. Click text on the photo, choose its font, then drag it into place.

5. Use the Save Image button in the top bar. It opens a small save options panel with file name, save location, and transparency options. Above the preview you can toggle Layers, GRID, and SNAP. Use the + button in Layers to add either a Text Layer or an imported image layer. Text and stickers have three on-photo handles: rotate, scale, and stretch/pinch in any direction. You can also optionally save an editable project for reopening later from the Projects button.
