Settings / Help

1. Hover over Frame Template on the left to open the dropdown. Frame folders become category/subcategory filters automatically; after filtering, hover previews a frame live and click selects it.

2. Set the background matte first. It can stay a classic box, use a background image, or become a Triangle / Circle / Hexagon. Use Resize Box to move, rotate, scale, or squish it.

3. Upload an image or paste a direct image URL. Main Image now keeps its controls open in the section itself for Zoom / Position / Rotation / Fit / Fill.

4. Main Label and Extra Text are on the left. Click a text object on the photo to open the Font Selector; hover fonts for a live preview and click one to keep it.

5. Use Save Image for PNG output. Use Export to create a shareable project ZIP containing project.json, a preview, and portable image data; use Import to reopen one. In Layers, Merge Down permanently flattens a layer with the one immediately below it.

Workspace Selection & Zoom

Drag a box across empty workspace to select multiple text/sticker/image layers, then press Delete to remove the selection. Mouse-wheel over the workspace zooms the editing view only; it does not change saved object size or position. Hold Shift while wheeling to use normal scrolling instead.

Project Sharing

Open Projects in the top bar to Import or Export a project. Exported projects use the .emx extension. An EMX file is a self-contained project package (ZIP internally) that Evidence Photo Composer can reopen directly. Imported projects are automatically stored under PROJECTS\Imported and appear in Recent Projects.

Merge Layer Cache

Merge Down creates a temporary flattened PNG in PROJECTS\cache. When you save an editable project, any merged PNG it uses is copied into the project SOURCES area, so clearing this cache will not damage already-saved projects. Clearing it can remove temporary merged files used only by current unsaved work, so save your project first if you want to keep those merges.
